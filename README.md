# Drawing Workspace

**GitHub Pages:** https://leetj94-lab.github.io/engineering_drawing/

A functional engineering drawing-management concept using original structured SVG/XML
samples. All diagrams, equipment, standards and metadata are synthetic; no employer
screenshots, code, layouts or drawings are included.

## What works

- Search by equipment ID, drawing number, title or discipline; one equipment can link
  to a P&ID, arrangement and electrical single-line drawing.
- Zoom, pan, fit, focus selected objects and toggle equipment/pipes/instrument/OPC layers.
- Select actual SVG objects to inspect IDs, canonical equipment tags and symbol standards.
- Follow **OPC = Off-Page Connector** to the reciprocal connector on another sheet.
  Service codes, target objects and reverse references must agree; broken links are blocked.
- Extract title-block fields and object metadata from the actual SVG/XML nodes, not
  hardcoded sidebar values. Download extracted JSON or the self-contained source SVG.
- Compare pump drawing B/C revisions side by side; highlight one added pump and one moved
  instrument. This is **object-level comparison**, not full CAD/pipe/text geometry diff.
- Validate title-block completeness, identity/revision consistency, symbol metadata,
  canonical equipment tags and reciprocal OPC references.
- Findings now zoom to their actual SVG object; Next issue cycles between invalid
  objects and a red-outline legend identifies the count. Title-only findings open
  the extracted title-block panel. Broken OPC navigation remains blocked.
- Add revision/object-anchored review notes, locate their anchors and resolve notes.
  Notes persist in localStorage, not a shared review database.
- Print/export through the browser print dialog (including PDF where the browser supports it).
- Open the same equipment in master_data or Digital Twin without losing its canonical ID.

## Try it

1. Open pump distribution. Click the blue AHU-SUP OPC to continue on the air-handling
   drawing; Back returns to the prior sheet/object.
2. Title block displays fields extracted from the SVG. Export metadata to inspect JSON.
3. On pump revision C, Compare revisions shows CWP-C added and PT-101 moved.
4. Open Draft validation exercise → Checks; locate invalid objects on the drawing.
5. Select an equipment object, open Review and add an anchored note; refresh to see
   persistence. Master/twin links open the same equipment context.

## Source and main-branch deployment

**Pages → Deploy from a branch → main → /(root)**.
Root HTML/JS/CSS and drawings/ are committed ready to serve. .nojekyll prevents Jekyll
processing. The workflow validates source/generated files; branch Pages publishes them.
There is no ChatGPT hosting or backend dependency.

```sh
npm run build
npm test
python3 -m http.server 8000
```

Requires Node.js 22+ and Python 3.12+ for tests. No third-party runtime/build dependencies.
Edit src/ and scripts/generate-drawings.mjs; build regenerates drawings, root publication
and dist/ preview. Commit source, drawings/ and root output together to main.

- src/catalog.js: source drawing definitions, canonical asset mapping and sample symbols.
- scripts/generate-drawings.mjs: deterministic original SVG generation.
- src/xml.js: DOMParser extraction from the loaded XML.
- src/domain.js: OPC resolution, validation, search, comparison and review state.
- scripts/validate-svg.py: stdlib XML validation against generated bytes.

## Boundaries

The symbol catalog and rule IDs are illustrative conventions, not certified engineering
standards. These diagrams are not approved engineering designs or suitable for construction.
No DWG/RVT/PDF conversion or OCR is claimed. Source drawings are bundled/allowlisted; there
is no arbitrary SVG upload. Introduce a sanitizer, CAD-conversion pipeline and server-side
processing if supporting untrusted uploads. App metadata and review notes are browser-local.
No cross-app data synchronization, production access control or approval system is present.

Optional Google Fonts fall back to system fonts; all drawing and application logic is local.
